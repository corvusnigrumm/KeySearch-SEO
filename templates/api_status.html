Asistente de Autenticación OAuth

Este asistente genera automáticamente un Refresh Token válido usando el flujo OAuth 2.0 de Google. Solo necesitas tener configurados el Client ID y Client Secret.

1

Configura Client ID y Client Secret

Asegúrate de haber guardado tus credenciales OAuth en la pestaña "Configuración Manual".

2

Agrega la URI de redirección en Google Cloud Console

En tu proyecto de Google Cloud, ve a APIs & Services → Credentials, edita tu cliente OAuth y añade esta URI a "URIs de redireccionamiento autorizadas":

http://localhost:8001/api/google-ads/callback
3

Haz clic en el botón para iniciar la autenticación

Se abrirá la pantalla de consentimiento de Google. Autoriza la aplicación y el token se guardará automáticamente.
